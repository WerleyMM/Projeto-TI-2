# Projeto-TI-2
Projeto de TI 2 do curso de ciências da computação da turma do 2º semestre de 2026

Esse projeto conta com a criação de um site para divulgação de jogos indies brasileiros a qual estamos desenvolvendo em um grupo pequeno de duas pessoas, por enquanto eu fiquei responsável pelo catalogo de jogos e pelo site da empresa/Publisher que queira divulgar seu jogo.

Usamos HTML, JAVA SCRIPT, JSON, GITHUB, VSCODE, entre outros.

Para testar e usar o estagio atual do projeto, você precisa usar o VSCODE e colar todas os arquivos conjuntos dentro do programa, após isso, será necessário usar o live-server para execução dos arquivos.
